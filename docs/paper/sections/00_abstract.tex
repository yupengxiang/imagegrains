\begin{abstract}
自然堆积骨料的视觉筛分任务可以定义为二维图像观测到具有筛分语义的粒径级配映射。不同于机械筛分依据颗粒通过筛孔的行为和各筛级质量定义级配，视觉筛分可以从单目图像中提取骨料的可见轮廓与实例数量，因此其任务被分为三个链路：接触颗粒分离、像素尺度恢复以及数量到质量的统计转换三个问题。本文面向混凝土骨料颗粒智能筛分赛题，构建“实例分割--物理测量--等效粒径筛分--质量级配代理--任务输出”的分层方法。基于 ImageGrains 2.0 / Cellpose-SAM 预训练模型获得独立颗粒实例，并通过尺度标定计算毫米级长短轴、面积和形貌特征；骨料几何被近似为椭圆，短轴作为当前筛分等效粒径基线，使用 $w=d^{\gamma}$ 建立质量代理权重，进而计算筛级比例及 $D_{10}/D_{50}/D_{90}$。同一组实例几何同时用于二维投影形貌分类和异常候选筛查。

实验使用的三张自然堆积真实图像共得到 3858 个颗粒实例。在统一的 $\boldsymbol{\theta}=(1,0,0)$、$\gamma=3$ 设置下，数量型 $D_{50}$ 分别为 6.0、7.6 和 5.2~mm，质量代理 $D_{50}$ 分别为 23.5、27.5 和 14.1~mm；三个场景均向粗端移动，说明按实例个数统计与按质量相关权重统计会得到不同的级配判断。算法推理速度约为 27~s/张。本文工作的重点是把成熟的预训练实例分割、可追溯物理尺度和显式统计模型连接成一条可运行、可复算的骨料视觉筛分链。

\textbf{关键词：} 混凝土骨料；实例分割；Cellpose-SAM；粒径级配；视觉筛分；质量代理
\end{abstract}
