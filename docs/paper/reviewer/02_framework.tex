\section{总体框架与技术路线}
\label{sec:r-framework}

技术路线需要同时满足三项约束：分离自然堆积中的接触颗粒，减少现场重新标注训练，并让最终输出由可解释的物理量和统计规则生成。传统阈值/分水岭实现简单，但对背景、阴影和弱接触边界敏感；监督式实例分割能够针对赛题训练，却依赖代表性实例标注并面临现场域变化；多视角或深度方案可恢复更多三维信息，但会增加设备、标定和布置复杂度。预训练颗粒实例模型已经具备较强的通用边界识别能力，赛题特有的毫米尺度与级配语义则可以放在下游显式建模。基于这一分工，本文采用 ImageGrains 2.0 / Cellpose-SAM 作为上游实例分割基座\cite{stringer2021cellpose,pachitariu2025cellposeSAM,mair2026imagegrains2}。

系统采用单向、可追溯的数据链，如图\ref{fig:r-architecture}。处理从图像和尺度参考出发，依次得到实例掩膜、毫米级几何量、筛分等效粒径和质量代理级配；形貌与异常由同一组颗粒几何并行计算，最后汇总为场景级报告。本文结果统一使用固定的 $\boldsymbol{\theta}=(1,0,0)$ 和 $\gamma=3$，运行过程中不根据最终级配反向调整参数。代码层保留外部机械筛分数据可用时重新估计 $\boldsymbol{\theta}$ 与 $\gamma$ 的接口，但该接口不参与本文结果计算。

这种结构把不同来源的误差保留在可检查的位置。预训练模型负责实例边界，标准化成像和尺度参考决定毫米量，筛分等效粒径与质量代理模型决定统计口径；出现异常结果时，可以沿这三层逐级定位，而不必把误差吸收到一个端到端黑箱中。现场推理只需要单目成像、尺度校验和固定配置计算，主要时间可以用于图像质检和失败恢复。与直接从图像回归级配曲线的方法相比\cite{coenen2022learningToSieve,buscombe2020sedinet}，这一结构减少了模型自由度，同时保留逐颗粒物理解释和较低的现场数据依赖。

系统能否给出有意义的级配，首先取决于实例轮廓能否稳定转换为毫米几何量；随后才是二维几何与筛分统计之间的映射。下一节从成像尺度、实例分割和颗粒几何三个环节展开这一测量过程。
