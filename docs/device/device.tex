\textbf{现场使用原则：}
设备可采用同等规格替换，但需保持\textbf{固定俯视、尺度可追溯、照明稳定、CUDA 本地计算}。相机工作距离或焦距改变后重新确认尺度；实例结果出现大面积 merge/split 时优先改善采集条件并重拍。
